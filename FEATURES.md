# DROP - Sneaker & Streetwear Marketplace

## 🚀 Complete Feature List

### 📱 Core Screens (5 Main Tabs)
1. **Home** - Featured drops, countdown timers, AI recommendations, hot items
2. **Explore** - Search, filters, browse all products
3. **Cart** - Shopping bag, order summary, checkout
4. **Rewards** - Gamification, badges, challenges, leaderboard
5. **Profile** - User stats, settings, orders, wishlist

### 🆕 Additional Screens (17+ Feature Screens)
6. **Notifications** - Price drops, new drops, orders, social, rewards alerts
7. **Chat** - Real-time messaging with sellers
8. **Orders** - Order tracking with visual progress timeline
9. **Wishlist** - Save items, sort by price/date, total value
10. **Price History** - Visual charts with timeframes (7d, 30d, 90d, 1y)
11. **Size Guide** - US/UK/EU/CM conversion with measurement instructions
12. **Reviews** - User reviews with ratings, helpful votes, sorting
13. **Community Feed** - Social posts, likes, comments, user-generated content
14. **AR Try-On** - Virtual sneaker try-on with rotation controls
15. **Collections** - Organize items into custom folders
16. **Live Events** - Live streaming drops with real-time viewers
17. **Seller Profile** - View seller ratings, listings, bio, follow
18. **Onboarding** - 5-slide welcome flow for new users
19. **Seller Application** - 3-step form to become a seller
20. **Settings** - Notifications, appearance, regional, account preferences
21. **Recently Viewed** - Track and revisit viewed items
22. **Flash Sales** - Limited-time deals with countdown timers
